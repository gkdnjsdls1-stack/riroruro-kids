# 리로루로게임즈 (초등판)

초등학생이 게임 회사 「리로루로게임즈」의 신입사원이 되어 **버그(문제)를 고치며 게임을 출시하는** 학습 웹앱입니다.
수학·국어·과학 문제를 학년별(1~6편 = 1~6학년) 스테이지로 풀고, 월급으로 간식을 사서 옥상에서 알을 부화시켜요.

- 파일 하나(`index.html`)로 동작해요. 서버·DB·로그인 없음.
- 진도는 **그 기기 브라우저의 localStorage**(`riroruro.kids.v1`)에 저장돼요.

## 바로 쓰기

| 방법 | 하는 법 |
|---|---|
| 내 컴퓨터 | `index.html`을 더블클릭 |
| Vercel | 이 저장소를 Import → Framework: **Other** → Build Command 비움 → Output Directory 비움 → Deploy |
| GitHub Pages | Settings → Pages → Branch `main` / `(root)` → Save |

배포한 주소를 아이 폰 브라우저에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 주요 기능

- **입사 서류 → 입사 테스트**: 과목별로 시작할 편을 정해요.
- **건물 층**: 3F 수학 · 4F 국어 · 7F 과학 개발실, 2F 버그 수리실(틀린 문제), 1F 은행, 8F 인사팀, 옥상 부화장.
- **스테이지 흐름**: 개념 카드 → 게임 테스트 5문제 × 3번 → 최종 점검(10문제 중 9개) → 다음 날 확인 3문제 → ⭐ 완벽 습득. 편의 모든 스테이지를 완성하면 게임 출시 + 다음 편 열림.
- **문제 은행**
  - 수학 1~6학년 각 12단원 (2022 교과서 단원 이름)
  - 국어 1~6학년 각 12단원 (문법·어휘·맞춤법 주제 단원)
  - 과학 3~6학년 각 8단원 (2022 개정 교과서 단원) · 1~2학년은 통합 주제
  - 그림 문제: 수학 77개, 과학 23개, 국어 7개 생성기
- **보상**: 월급(테스트 300원, 최종 점검 보너스 900원) → 간식·옷 → 알 4종 부화, 캐릭터 20종 도감, 직급 6단계.
- **효과음**: Web Audio로 합성(외부 파일 없음). 8층·보호자 화면에서 끄고 켜기.
- **보호자 화면**(8층, 4자리 비밀번호)
  - 주간 리포트(이번 주/지난주, 과목별, 어려워한 개념 + 집에서 도와주기, 성과, 텍스트 복사)
  - 하루 판 수·이용 시간 제한, 학년, 효과음
  - **진도·알 직접 지정**: 저장이 날아갔을 때 편·스테이지 상태, 도감, 부화 횟수, 품은 알, 간식, 통장 잔액을 복구

## 폴더 구조

```
index.html        ← 배포용 완성본 (build.py로 만든 결과물)
build.py          ← src/ 를 합쳐 index.html 생성
src/
  base.html       ← 원본 엔진(개념중공업) + 테마 CSS
  building.js     ← 건물 층 구성
  kid.css         ← 초등판 스타일
  eggdata.js      ← 캐릭터 20종 데이터·그림
  lines.js        ← 캐릭터 대사
  kmath.js        ← 수학 3~6학년 문제 + 공통 도우미(KN/KC, 조사 처리)
  kmath12.js      ← 수학 1~2학년
  kfig.js         ← 수학 그림(SVG)
  kkor.js         ← 국어 1~6학년
  kkorfig.js      ← 국어 그림
  ksci.js         ← 과학 문제 원본(2015 단원)
  ksci22.js       ← 과학 2022 단원 재구성 + 과학 그림
  kid.js          ← 초등판 화면·게임 규칙(스테이지, 보상, 옥상, 개념 카드)
  parent.js       ← 보호자 화면·주간 리포트·이용 제한
  restore.js      ← 진도·알 직접 지정
  sfx.js          ← 효과음
```

## 고치는 법

1. `src/` 안의 파일을 수정
2. `python3 build.py` 실행 → 루트 `index.html` 갱신
3. 커밋·푸시 (Vercel을 연결했다면 자동 재배포)

> `index.html`을 직접 고치면 다음 빌드 때 덮어써져요. 항상 `src/`를 고치세요.

## 저장 데이터 주의

- 브라우저 기록/사이트 데이터를 지우거나, 다른 기기·다른 브라우저에서 열면 진도가 보이지 않아요.
- 그럴 땐 보호자 화면 → **진도·알 직접 지정**에서 원래대로 맞춰 주세요.
- 배포 주소(도메인)가 바뀌어도 저장소가 달라져요. 주소는 한 번 정하면 유지하세요.
